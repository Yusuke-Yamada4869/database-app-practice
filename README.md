# database-app-practice

## 概要
COACHTECH 教材 Tutorial 9-3「データベース操作ハンズオン演習」で作成した成果物です。
Laravelでマイグレーションにテーブルを作成した
シーダーを利用してテストデータを入れて、データを取得してURLと結びつけてサイトを表示させた

## 使用技術
- PHP 8.x
- Laravel 10.x
- MySQL
- マイグレーション、シーダー
-グーグルジェミニ
-コーチテックのAI

## 学んだこと
- マイグレーションを実行してテーブルを作ることでデータベースそのものをPHPとして出すことができた
- シーダーを利用してデータの挿入を学んだ
- 初めはエラーメッセージが出てサイト表示がされなかったが、routeにコードを足すことで表示させられたため、関連性を覚えた
